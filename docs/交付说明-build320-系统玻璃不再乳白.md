# 轻阅 Lite · build320 · 「星澜终端」换肤 · **系统玻璃不再乳白**

**日期**：2026-11-24 · **版本**：`CFBundleVersion = 320`
**依据**：你给��原型 `阅读App全息终端.html` + 你在 build319 上的真机反馈「**这些按钮不对吧，太白了点吧**」

## 一、你截图里「太白」的是什么

| 位置 | 组件 | 是什么 |
|---|---|---|
| 发现页顶上一排胶囊 | 章节 / 全部 / 状态 / 不限 … | **系统玻璃** |
| 点「🐶 长篇」弹出的**下拉菜单** | 书旗 / 番茄 / QQ阅读 … | **系统菜单** |
| 底部标签栏 | 终端 / 发现 / 搜索 / 设置 | **系统玻璃** |
| 分类筛选页的**所有按钮** | 今日 / 本周 / 本月 / 男性视角 … | **系统玻璃** |
| 阅读页底部面板 | 目录 / 大小 / 自检 | **系统玻璃** |

### ⭐⭐⭐ 根因：**App 从来没强制过外观**
- 那些是 **iOS 26 的系统玻璃**（`.glassEffect`）⇒ **系统按「当前外观」渲染** ⇒
- App 以前**跟着系统走（浅色）** ⇒ ⇒ 系统玻璃出**乳白色** ⇒ **深空底上像一排白板** ⭐⭐⭐
- 而 App 自己的卡片/背景是**深色** ⇒ ⇒ 两套不匹配（你截图里看得很明显）⭐⭐⭐

### ✅ 修法：**根部 `.preferredColorScheme(.dark)`**（一处）
⇒ 系统玻璃 / 菜单 / 弹窗 / 搜索框 / 标签栏 / 导航栏胶囊 **全部切到深色玻璃** ⇒ 与深空底融在一起 ⭐⭐⭐
⇒ **顺带修好**：导航栏标题之前是**黑字在深色栏上**（看不见）⇒ 现在是浅色 ✔

⚠️ **阅读正文不受影响**：纸色主题是**写死的颜色** ⇒ 照旧；只有「跟随系统」那一档会变深
（而原型里阅读页本来就是深色 ⇒ 正好对上）⭐⭐⭐
