## 一、发现页那个「黑色长块」—— 已修

**根因**：那一行是「加载更多」的行，**`List` 的行有默认底色**（深色下 = **纯黑**）⇒
书卡自己有玻璃底所以看不出来，**只有这行露出来是一整条黑块**。

**修**：所有行（含书卡行、「没有更多了」行）都加 `.listRowBackground(Color.clear)` ⇒ 行底透明 ⇒ 融进深空背景。

## 二、正文阅读 UI：照**柴阅**重做

> ⚠️ **先纠正一件事**：你让我搬的是**柴阅**，我一开始拿**栖阅**的 UI 反推件当参考了 ⇒ 已改成直接读**柴阅源码**（`github.com/Lincb522/Chaiyue`）。

### 柴阅的阅读页长什么样（读源码得出）

| 部件 | 柴阅 | 轻阅现在 |
|---|---|---|
| 顶栏 | **一整条玻璃胶囊**（高 56 / 圆角 28）+ **居中衬线书名** + 翻页信息 | 系统导航栏 + 一个小胶囊 |
| 底栏 | **异形玻璃面板**（上窄 32 / 下宽 45）= [‹][章节滑杆][›] + 4 个工具（**依次浮现**） | 矩形玻璃面板 |
| 「外观」图标 | **衬线体文字 “Aa”**（系统图标在中文环境会变「格式」） | 系统图标 |
| 日/夜切换 | 底栏一颗，**一键切** | 只能在设置面板里切 |
| 背景 | **四套皮肤**（宣纸/晴窗/星夜/烛灯）= 背景 + 字体 + 章节号装饰 + 强调色 | 一块纯色 |
| 正文 chrome 配色 | 跟着主题走 | **写死的浅色版** ⇒ 夜间主题上深灰字 + 黑控件底 ⇒ **看不见** |

### 这一版做了什么

1. **顶栏** → 整条**玻璃胶囊**（高 56 / 圆角 28）+ 居中**衬线**书名 + 第二行「章节名 · 页码」⇒ 并**隐藏系统导航栏**（柴阅的阅读页是自带 chrome 的全屏页）
2. **底栏** → **异形玻璃面板**（新加 `liquidGlassUneven`，系统 `glassEffect` 本来就接受任意 Shape）+ [上一章][章节滑杆][下一章] + 4 个工具（目录 / 大小 / **日·夜一键切换** / 自检）
3. **背景** → **皮肤底**（`ReaderSkinBackground`）：渐变 + 极轻层次，替代原来的纯色
4. **分页画布改透明** ⇒ 原来它刷一层 `theme.bg` ⇒ **会把皮肤底整个盖住** ⇒ 现在透出来
5. **深色适配**：阅读页 chrome 原来全是写死的浅色版 ⇒ **夜间主题上等于隐形** ⇒ 全部改成随阅读主题自适应
   （面板纱层：浅色底用白纱 / **深色底用黑纱** ⇒ 玻璃才通透、不是乳白板）

### ⭐ 还没做的：柴阅的**章节号装饰**

柴阅每套皮肤在**章首页**画自己的章节号装饰（宣纸=朱印「第X章」、晴窗=描边大号、星夜/烛灯=居中号）。
⇒ 这一步要动 **CoreText 排版核心** ⇒ **风险高**（排版出问题是这个 App 最难查的一类）⇒ **单独一轮做**，先让你看这版的观感 ⭐
