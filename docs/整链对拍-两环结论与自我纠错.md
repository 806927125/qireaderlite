# 整链对拍：两环实测结论（2026-11-18）

## 台子（可复现 / 不依赖网络 / 秒级）
1. **录真实响应**当 fixture（curl 一次存盘）
2. **老引擎侧**：Node + `test/harness.js`（jsdom）+ `nativeMock` 按 URL path 匹配喂 fixture ⇒ 结果当 **oracle**
3. **Swift 引擎侧**：`SourceEngine` + `FixtureTransport`（同 fixture）+ **Node 后端**（Linux 可跑 ⇒ 沙盒 3 秒一轮）
4. **逐项求差集** ⇒ 差集 = **待查清单**（不是「错误」）

## 两环实测（NovelHub 聚合源 · 同一份 fixture）
| 环 | 老 WebView 引擎 | 自研 Swift 引擎 | 差集 | 判定 |
|---|---|---|---|---|

| bookInfo（详情） | name/author/intro **全空** | name/author/intro **全空** | **0** | ⚠️ **两边都错 ⇒ 共同缺口** |

⇒ ⭐⭐⭐ **「差集 = 0」有两种含义：等价 / 两边都错** ⇒ ⇒ **门禁必须配「绝对断言」（不能两边都空）才能区分** ⭐⭐⭐
⇒ ⇒ **真正的缺口在「共同缺口」**：聚合源的详情字段全是 `@js:`（且要 `result` = 页面文本）⇒ 下一轮查这条链

## ⚠️ 一次自我纠错（记录下来，别再犯）
- 我曾判定「自研引擎不容许 **jsLib 顶层 return** ⇒ 整源加载失败」并据此改了引擎（IIFE 包装）
- ⭐ **证伪**：原始 jsLib 加载**成功**；顶层 return 的规则求值也**成功**（`{"x":1}`）
  ⇒ 那个「Illegal return statement」是**我注入解锁桩时破坏了 jsLib 语法**造成的假象 ❗❗
- ⇒ **改动已全部撤回**（无依据的改动 + 已知副作用：导出码会被 return 跳过）
- ⇒ **教训**：⭐ **探针要先自证**（先证明「原始输入真的坏」再下结论）⭐⭐⭐
