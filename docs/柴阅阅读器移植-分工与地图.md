## 五、编译设置（⭐⭐⭐ 分层照抄柴阅，别再混）⭐⭐⭐

| 层 | 柴阅出处 | 我们的 target | 设置 |
|---|---|---|---|
| 柴阅 SPM 包层 | `Packages/ReaderCore` | `ChaiyueReaderKit` / `ChaiyueReaderServices` | tools 6.0 + `swiftLanguageMode(.v6)`，**无默认隔离** |
| 柴阅 App 层 | `App/project.yml` | `ChaiyueReader`（阅读界面 + shim） | `swiftLanguageMode(.v6)` + `.unsafeFlags(["-default-isolation","MainActor"])` + `ApproachableConcurrency` |
| 引擎侧（按 Swift 5 写的） | — | `ChaiyueModels` / `ChaiyueEngine` / `LegadoEngine` | **钉死 `.v5`**（tools 6.0 会把它们默认拖进 v6 ⇒ 探针炸） |
| 探针 / 测试 | — | 5 个探针 + 2 个测试 target | **钉死 `.v5`** |

⚠️⚠️⚠️ **坑位清单**（每个都真炸过）：
1. `swiftLanguageModes` 是**包级**参数 ⇒ 改用 target 级 `swiftSettings: [.swiftLanguageMode(...)]`，且必须排在 `dependencies`/`path` **之后**。
2. `SWIFT_DEFAULT_ACTOR_ISOLATION: MainActor` 在 SPM 里**只能用** `.unsafeFlags(["-default-isolation", "MainActor"])`；
   `.enableUpcomingFeature("DefaultActorIsolation")` **不生效**（错误一字未变 ⇒ 极容易误判）。
3. 平台下限必须 **iOS 17 / macOS 14**（柴阅用 `@Observable`）。
4. **`#if` 守卫必须把 `import` 一起圈进去** —— 否则 macOS 编译 App target 照样 `no such module 'UIKit'`（CI27 实锤）。
5. **同名类型会炸**：宿主 `Book`/`Chapter`/`BookSource` vs 柴阅同名 ⇒ 宿主一律走 `LegadoEngineHost.*` 别名；
   包内加 shim 前先 `grep -rn "struct <类型名>"` 全仓查重（`PressStyle`/`Metrics` 都撞过）。
6. **`@MainActor (…) -> Void` 的 sendability 在 v5 与 v6 里推断不同** ⇒ 跨模块实现协议时**两侧都显式写 `@Sendable`**
   （本地已复现：`sendability of function types … does not match requirement`）。
7. **删 shim 前要扫调用点**（`.方法名(`），不能只看类型名 —— `DesignCompat.swift` 只含扩展方法 ⇒ 曾被误删。

⭐⭐⭐⭐⭐ **「宿主可见性面」是这轮最大的坑**（CI28）⭐⭐⭐⭐⭐：
SwiftPM target 里的类型默认 **internal** ⇒ **跨模块（宿主 App）看不见** ⇒
CI 会报一屏 `cannot find type 'AppModel' / 'ReaderLaunch' / 'ReaderContainer' / 'ReaderThemeSpec' …`。
⇒ **只开宿主真正要用的那几个面**（`public`），**不要「全 public 化」**：
全 public 会牵连 `AppearanceStore` / `IslandCenter` / `LocalVoice` 一整串 ⇒
它们的**公开成员的类型**又得再 public ⇒ **雪崩** ⭐⭐⭐。
⇒ 已开的面（门禁 `reader-chaiyue-host.test.js` ⑥ 盯着）：`ChaiyueReaderLibrary` `AppModel`
`ReaderLaunch` `ReaderContainer` `ReaderThemeSpec` `ReaderThemeMode` `CustomReaderTheme`
`ReaderThemeStore` `ReaderFontChoice`。
⇒ ⚠️ **`public struct` 的默认 memberwise init 是 internal** ⇒ 宿主 `ReaderLaunch(book:…)` 会被拒
⇒ **凡宿主要 new 的类型 ⇒ 必须显式写 `public init`** ⭐⭐⭐
⇒ ⚠️ **`public` 的存储属性不能用 internal 类型** ⇒ 所以只 public **成员**，其余属性保持 internal ⭐⭐⭐

⭐⭐⭐⭐⭐ **条件编译守卫的三条纪律**⭐⭐⭐⭐⭐：
① **import 必须一起圈进守卫**（`SeededRandom` / `DesignCompat` 各炸过一次）⭐⭐⭐
② **别用 `canImport(SwiftUI)` 当 iOS 守卫**（macOS 有 SwiftUI、没有 UIKit ⇒ 等于没守）⇒ 用 `#if os(iOS)` ⭐⭐⭐
③ 守卫要**配平**（开头 `#if` 与结尾 `#endif` 都要有）⭐⭐⭐

  public/@Observable/Codable/sendability 规则**（本轮三条 sendability 修法就是这样验出来的）
